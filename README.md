# Bus Reservation System

## 📌 Project Overview

The Bus Reservation System is a Java-based console application designed to manage bus reservations. The application allows users to view available buses, search for buses, reserve seats, and manage booking information.

## 🛠️ Technologies Used

* Java
* Java OOP (Object-Oriented Programming)
* Java Collections
* Git
* GitHub

## ✨ Features

* View available buses
* Search for buses
* Check seat availability
* Book/reserve bus seats
* Manage passenger details
* Display reservation details

## ▶️ How to Run

### Requirements

* Java JDK installed
* Any Java IDE such as IntelliJ IDEA, Eclipse, or VS Code

### Steps

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project in your Java IDE.

3. Navigate to the main Java file.

4. Run the `main()` method.

5. Follow the instructions displayed in the console.
